# Laboratório Prático de Diagnóstico de Redes N1
> Este repositório é focado no diagnóstico de conectividade, documentação de procedimentos práticos e chamados de rede no ecossistema Windows. 
---
## Visão Geral

Esta documentação foi desenvolvida com o intuito de simular o dia a dia de um Analista de Suporte Técnico Nível 1 em ambientes corporativos. Cada tema faz uma abordagem com ferramentas de comandos via terminal, testes de conectividade e metodologias de troubleshooting (solução de problemas).
